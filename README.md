# My Digital Portfolio | Martim Galamba

Welcome to my personal portfolio repository. This is where I showcase my journey, projects, and expertise as an aspiring Software and AI Engineer.

## 👋 About Me

I am a passionate developer currently focusing on bridging the gap between robust software engineering and cutting-edge Artificial Intelligence. This portfolio is my digital home, designed to showcase my technical skills, creative problem-solving, and the projects I've built.

### Current Features
- **Personal Branding**: A clean, modern interface reflecting my design philosophy.
- **Interactive Role Showcase**: A dynamic typewriter animation highlighting my core focus areas.
- **Direct Access**: Quick links to my professional background via GitHub, LinkedIn, and my updated CV.
- **Performance First**: Built with a focus on speed, responsiveness, and clean code.

## 🛠️ My Tech Stack

I chose these technologies to ensure my portfolio is scalable, performant, and maintainable:

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/) - Utilizing the latest server-side rendering and routing features.
- **Library**: [React 19](https://react.dev/) - For a reactive and modern user experience.
- **Language**: [TypeScript](https://www.typescriptlang.org/) - Ensuring type safety and reliable code across the project.
- **Styling**: Vanilla CSS - Custom-built design system with modern CSS variables.
- **Layout**: Fully responsive system using Flexbox and Grid.

## 📂 Project Structure

- `app/`: Contains the core logic and styling of the application.
  - `globals.css`: My custom design system and style tokens.
  - `page.tsx`: The heart of the portfolio interface.
- `public/`: Stores my professional assets, including my CV and icons.

## ⌨️ Development

If you want to run my portfolio locally, follow these steps:

1. **Clone the repo**:
   ```bash
   git clone https://github.com/martimgalamba7/website.git
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Spin up the dev server**:
   ```bash
   npm run dev
   ```
